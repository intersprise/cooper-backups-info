# Cooper Backups

Cooper Backups is a private, personal-use backup application
maintained by the GitHub user intersprise.

The application uses rclone and restic to store encrypted backups
of the owner's server in the owner's Google Drive account.

Google Drive access is used to create, read, verify and manage
backup files. This application is not offered as a public service
and does not accept other users.

Backup contents, passwords and access tokens are not published
on this website or in this repository.
